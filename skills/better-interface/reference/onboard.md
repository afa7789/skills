# Improve onboarding

Optimize time to first value, not the number of tutorial steps.

1. Define the first meaningful outcome and the minimum information required to reach it.
2. Prefer contextual guidance and useful defaults over tours, modals, and setup ceremony.
3. Make optional education dismissible and recoverable from help or settings.
4. Give every empty state orientation, value, and one clear next action.
5. Preserve advanced paths for experienced users; do not force repeat onboarding.
6. Measure completion, abandonment, and the first-value event when instrumentation exists.

Use `better-writing` for copy, `better-layout` for progression and disclosure, `better-accessibility` for focus and announcements, and `better-ui` for restrained feedback. Verify first run, return visit, skipped onboarding, and no-data states.
